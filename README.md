# 스마트 여행 플래너 (Smart Travel Planner)

도쿄 3박 4일 여행을 준비하면서 직접 만든 **여행 일정·동선 관리 웹앱**입니다.
AI를 활용해 제작했으며, 설치 없이 브라우저(모바일 포함)에서 바로 사용할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 일차별 일정 관리 | Day 탭으로 날짜별 일정을 나누어 추가·수정·삭제 |
| 드래그 정렬 | 일정을 끌어서 순서를 바꾸면 이후 일정 시간이 자동으로 다시 계산됨 |
| 이동 시간 계산 | 앞뒤 장소 사이의 대중교통·도보 이동 흐름을 보여 주고 일정 시간에 반영 |
| Google 지도 연동 | 장소 위치 보기, 구간 길찾기, 하루 전체 동선 보기 |
| 주변 맛집·카페 | 선택한 장소 주변의 맛집·카페 추천 |
| 카테고리 | 관광/명소 · 맛집/카페 · 숙소 · 공항/이동 · 쇼핑 |
| 저장·공유 | 일정을 저장하고, 공동 편집 링크로 일행과 함께 확인·수정 |
| 시트 불러오기 | Google 스프레드시트에 정리한 일정을 불러오기 |
| 여행 정보 수정 | 여행 제목과 전체 날짜를 화면에서 바로 변경 |

## 사용 방법

- GitHub Pages로 배포되어 있어 저장소 오른쪽 **About**의 링크로 바로 열 수 있습니다.
- 로컬에서는 `index.html`을 브라우저로 열면 됩니다.

## 기술

HTML · JavaScript · Tailwind CSS · Firebase(클라우드 저장·공유) · Google Maps 링크 연동 · GitHub Pages

## 제작 배경

도쿄 여행을 준비하면서 일정·동선·이동 시간을 한 화면에서 관리하고 일행과 공유하기 위해 AI와 함께 만들었습니다.
